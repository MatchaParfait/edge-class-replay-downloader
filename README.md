# 课堂回放下载 Edge 扩展 v2.2.1

专用于中国矿业大学课堂回放页面。只下载当前账户有权访问的普通 MP4 录像，不绕过登录、访问权限或 DRM。

## 这次重做了什么

- 不再把缩略图改后缀，也不再用“资源 ID +2”猜地址。
- 读取播放器使用的录像详情接口，明确区分教师、课件两种视角。
- 默认只选择课件；可只选教师，也可以两者都选。不会下载学生视角。
- 一节录像有多个分段时全部保留；缺少某种视角时显示“无此视角”，不冒充其他视角。
- 独立管理标签页，支持按周次、日期筛选、勾选录像和导出真实链接。
- 后台持久化扫描和下载队列，支持 1–4 个文件并发、进度显示、重复提交去重和失败重试。
- 文件按“课程 / 周次 / 日期时间及视角”命名。
- 自动跟随来源页面的课程切换，显示当前课程名称并重新扫描；下载和导出前再次核对来源，阻止过期列表。
- 课程列表和视频播放页右侧提供下载浮窗，点击后展开并识别所在页面；不必离开课堂页面。

## 安装或更新

1. 在 Edge 打开 `edge://extensions`，启用“开发人员模式”。
2. 首次安装：点击“加载解压缩的扩展”，选择本文件夹。
3. 更新原版：在扩展卡片点击“重新加载”，并确认新增的站点访问权限。
4. 刷新原先打开的课堂页面，清除原版残留脚本。无需退出登录。
5. 进入课堂实录或播放页，点击页面右侧的下载按钮；在这些页面点击工具栏上的插件图标，也会展开或收起浮窗。

插件目录：

```text
E:\codex\课堂回放\edge-class-replay-downloader
```

旧版已备份到同级 `edge-class-replay-downloader-backup-时间` 文件夹。旧版推测出的链接不会自动导入新版。

## 页面浮窗

- 课程列表页：展开后自动识别当前课程的全部已加载录像，继续支持课程切换和批量选择。
- 视频播放页：展开后识别当前这一节的教师、课件视角及全部分段。
- 顶部“收起浮窗”按钮或 Esc 可收起；收起不会取消后台扫描、排队或正在下载的文件。
- 再次点击页面右侧的下载按钮即可展开，已保存的视角和勾选状态会恢复。
- 浮窗只关联它所在的页面，不能误选另一个云课堂标签页。
- 同时打开课程列表、播放页或独立管理页时，各标签页的扫描互不覆盖，下载队列仍统一管理。
- 顶部“打开独立管理页”图标保留原来的完整管理页。扩展的其他筛选、导出、并发、去重和重试功能不变。
- 右侧浮窗覆盖页面的一部分；不操作浮窗时可以收起，不会改变视频播放器的布局。

## 下载步骤

1. 正常登录课堂网站，进入“课堂实录”，在左侧选择一门课程，等待列表加载。
2. 点击页面右侧的下载按钮展开浮窗，自动关联当前页面。
3. 浮窗自动读取当前页面录像；“重新识别”可手动重新读取。独立管理页仍可在顶部选择来源。
4. 勾选“课件”“教师”中的一种或两种，按需要选择周次、日期和录像。
5. 确认底部文件数量及合计体积，点击“下载选中项”。

下载和导出只处理**当前筛选结果中已勾选**的录像，不会悄悄下载被筛选隐藏的录像。

若打开的是“播放页”，只扫描那一节录像，不代表整门课程。在来源页面更换课程后，浮窗会自动重新提取，并清空上一门课的周次、搜索和勾选状态；之前已提交的下载队列不会被覆盖。

独立管理页只跟随顶部选定的来源标签页，浮窗只跟随所在页面。页面加载中、已关闭或尚未同步时，旧录像不能下载或导出。扫描中切换课程时，上一门课的迟到接口响应不会混入新课程。

## 保存位置

使用 Edge 默认下载目录，例如：

```text
下载目录/
  课堂回放/
    科技论文写作/
      第1周/
        2026-09-07_1855-1950_课件_第01段_文件ID.mp4
```

课程名、日期、视角、分段号及文件 ID 均来自实际录像数据。不同视角不会混到同一个名字下。

## 队列与恢复

- “暂停排队”：停止启动新文件，已在下载的文件继续；“继续排队”恢复提交。
- “移除等待中的任务”：仅移除尚未开始的任务，不删除已下载文件。
- 失败原因直接显示在队列中；“重试失败”优先尝试恢复原下载，无法恢复时先让浏览器清理该失败任务的临时文件，再重新下载，不保证断点续传。
- 重试不会直接丢弃旧下载编号；清理失败时停止创建新下载并显示错误。若原任务已在浏览器中完成或恢复，则沿用原任务，避免重复下载。
- 不会删除或覆盖已完成的 MP4；只有与当前任务对应的失败记录会被清理。旧版已遗失下载记录的孤立 `.crdownload` 无法由扩展按路径清除，需要核对后单独处理。
- 已有任务会自动跳过。清除已完成记录后，可以重新下载这些文件。
- 关闭管理页不取消任务；浏览器仍需运行。浏览器重启后，未完成任务会尝试恢复；接口读取仍需要原课堂标签页保持登录。
- 要暂停、取消某个正在下载的文件，或处理浏览器安全提示，请打开右上角“浏览器下载记录”。
- 平台会话过期、原标签页关闭或平台结构变化会导致扫描失败，请重新登录或刷新后再扫描。

扩展不会覆盖 Edge 的安全设置。若每个文件都要求选择保存位置，可通过右上角“Edge 下载设置”自行调整。若浏览器阻止下载，请先检查提示和文件来源。
